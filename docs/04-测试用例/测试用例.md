## 0. 使用说明

1. **环境准备**：`npx vite --port 5175 --strictPort` 启动 dev server；浏览器用 Chrome 100+（headless 亦可）；Android 用例需真机（Android 10 / 14 各一台）。
2. **清数据基线**：浏览器 DevTools → Application → Storage → Clear site data（或 `indexedDB.deleteDatabase('cinema-db')` + `localStorage.clear()`）；Android 用「设置 → 应用 → 存储 → 清除数据」。
3. **等价类合并说明**：本套用例保持 1 AC : 1 TC 的粒度，**未做跨 AC 合并**，因为验收报告需按 AC 逐条判定。仅在同一 TC 内用"变体"覆盖同一 AC 的多个等价类（如 AC-12 的三个文件错误分支）。
4. **判定规则**：全部"预期结果"项均满足 → 通过；任一不满足 → 不通过；环境不具备（真机/真实服务器/外部依赖）→ 未验证，须在报告中写明原因。
