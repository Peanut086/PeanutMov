## 0. 使用约定

1. **单一真值**：本文列出的每个值与 `src/styles/tokens.css` 中的 CSS 变量一一对应；改值必须同时改两处。
2. **层级规则**：组件只允许使用 semantic / component 层变量，**禁止**直接引用 `--p-*` 原始色板。
3. **单位**：尺寸一律 `px`（1px ≈ 1dp @mdpi），比例用无单位比值；时长 `ms`。
4. **色彩表示**：`#hex` + `rgb()` 双写。半透明色给 `rgba()`，透明值基于白/黑叠加，不引入第三种基色。
5. **深色为默认**：`<html data-theme="dark">`，浅色通过 `data-theme="light"` 切换（见 §9）。
6. **对比度**：文中标注的对比度均由 WCAG 2.1 相对亮度公式实算（非估算），基准见 §12。

## 1. 设计定位

| 维度 | 结论 |
| --- | --- |
| 气质 | **深色影院**：低明度背景把注意力交给海报与画面；金属暖金作为唯一强调色 |
| 关键词 | 沉浸、克制、无干扰、内容优先 |
| 反面 | 不用大面积品牌色铺底、不用霓虹渐变、不用玻璃拟态堆叠、不用圆角过大的"糖果感" |
| 与竞品差异 | 无广告位、无运营 Banner、无"猜你喜欢"诱导；首页只有"继续观看 + 最近添加" |
| 品牌色选择理由 | 琥珀金 `#F0A82E` 在纯黑背景上对比度 9.68:1，既做强调色又不刺眼；与"影院幕布/放映机暖光"的联想一致 |

**视觉修辞**：背景三层（base → surface → elevated）模拟剧场从"厅外"到"座位"到"屏幕反光面"的层次；所有浮层（控制条、Sheet）都用"压暗 + 轻微上浮"而非描边，避免画面出现"框"。

## 5. 阴影与模糊

### 5.1 Elevation（深色）

| Token | 值 | 用途 | 视觉意图 |
| --- | --- | --- | --- |
| `--shadow-1` | `0 1px 2px rgba(0,0,0,0.4)` | 贴附于表面的元素（Segmented 选中块、小徽标） | 几乎不可见，只消除"贴纸感" |
| `--shadow-2` | `0 2px 8px rgba(0,0,0,0.45)` | 浮动卡片、下拉菜单 | 轻微离面 |
| `--shadow-3` | `0 8px 24px rgba(0,0,0,0.52)` | Toast、悬浮按钮 | 明确离面 |
| `--shadow-4` | `0 16px 48px rgba(0,0,0,0.6)` | Dialog、BottomSheet | 强离面，配合遮罩 |
| `--shadow-focus` | `0 0 0 2px rgba(240,168,46,0.55)` | 键盘/焦点环 | 品牌色光环，不改变布局 |

深色阴影策略：**黑色阴影在深色底上可见度低**，因此离面感主要靠"surface → elevated 的明度提升 + 描边"，阴影只作为辅助。禁止使用带颜色的发光阴影（neon glow）。

### 5.2 模糊

| Token | 值 | 用途 |
| --- | --- | --- |
| `--blur-player-hud` | `saturate(140%) blur(16px)` | 播放器 HUD（音量/亮度/快进浮层） |
| `--blur-sheet` | `saturate(120%) blur(24px)` | iOS 风格 Sheet 顶栏（可选，Android 默认不用） |
| `--blur-skeleton` | `none` | 骨架屏**不做**模糊（性能优先） |

`backdrop-filter` 使用限制（性能约束 NFR-P02）：
- 同一屏最多 **1 层** 模糊元素；
- 模糊层不覆盖滚动列表（只在固定定位的浮层上使用）；
- 帧率不足或低端机时，通过 `@media (prefers-reduced-motion)` 与运行期降级关闭模糊（退化为 85% 不透明黑底）。

## 6. 布局

### 6.1 安全区

`index.html` 已设置 `viewport-fit=cover`；所有全屏/顶底吸附元素必须处理安全区：

```css
padding-top: var(--safe-top);      /* env(safe-area-inset-top, 0px) */
padding-right: var(--safe-right);
padding-bottom: var(--safe-bottom);
padding-left: var(--safe-left);
```

| Token | 值 |
| --- | --- |
| `--safe-top` | `env(safe-area-inset-top, 0px)` |
| `--safe-right` | `env(safe-area-inset-right, 0px)` |
| `--safe-bottom` | `env(safe-area-inset-bottom, 0px)` |
| `--safe-left` | `env(safe-area-inset-left, 0px)` |

规则：
1. 页面左右内边距使用 `max(var(--layout-page-padding-x), var(--safe-left/right))`，横屏时不被刘海压住（AC-53）。
2. 底部 TabBar 高度 = `56px + var(--safe-bottom)`；页面底部留白同步加上该值。
3. 播放器横屏时字幕与左右控制按钮再内缩 `--safe-left/right`，上下用 `--safe-top/bottom`。

**留白归属（每向只有一个负责方，禁止叠加）**：

| 方向 | 负责方 | 说明 |
| --- | --- | --- |
| 顶部 | `AppHeader` | 自带 `padding-top: var(--safe-top)` |
| 左右 | 各页顶栏与 body | 按 `--layout-page-padding-x` 响应式取值（16/24px） |
| 底部 | `App.vue` 的 `.app-content--tabbar` | 统一预留 TabBar 高度 |

`SafeArea` 只保留 `--safe-left/right`（刘海横屏才非零），不再施加内容留白。历史缺陷：`SafeArea` 曾同时加左右 16px，与页面叠加后 390px 屏内容从 32px 起、海报 156.5px，比本节算式得到的 173px 窄约 10%。

### 6.2 关键高度

| Token | 值 | 说明 |
| --- | --- | --- |
| `--layout-header-height` | 52px | 顶栏内容高度（不含安全区；总高 = 52 + safe-top） |
| `--layout-tabbar-height` | 56px | 底部 Tab 内容高度（总高 = 56 + safe-bottom） |
| `--layout-page-padding-x` | 16px（≥600px 时 24px） | 页面左右边距 |
| `--layout-content-max-width` | 720px | 大屏内容最大宽度（平板不拉伸成两列文字） |
| `--layout-grid-gap` | 12px（≥600px 时 16px） | 海报网格间距 |

顶栏构成：`[返回 44×44] [标题 flex] [右侧操作 44×44 ×0..2]`，左右各 16px 内边距，垂直居中。

### 6.3 层级（z-index）

| Token | 值 | 层 |
| --- | --- | --- |
| `--z-content` | 1 | 页面内容 |

## 7. 动效

### 7.1 时长与缓动

| Token | 值 | 用途 |
| --- | --- | --- |
| `--duration-fast` | 150ms | 颜色/描边变化、按下反馈、图标切换 |
| `--duration-base` | 200ms | 元素显隐、Toast 进出、Tab 切换 |
| `--duration-slow` | 300ms | Sheet 上滑、控制条淡出（**不用于页面转场**） |
| `--duration-skeleton` | 1400ms | 骨架屏扫光一个循环 |

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | 绝大多数过渡（快起慢收） |
| `--ease-decelerate` | `cubic-bezier(0.05, 0.7, 0.1, 1)` | 进入（从屏幕外滑入、Sheet 上滑） |
| `--ease-accelerate` | `cubic-bezier(0.3, 0, 0.8, 0.15)` | 退出（淡出、下滑收起） |
| `--ease-emphasized` | `cubic-bezier(0.05, 0.7, 0.1, 1)` | 需要"弹性感"的大位移（全屏切换） |

### 7.2 具体动效定义

| 场景 | 属性 | 时长 / 缓动 | 备注 |
| --- | --- | --- | --- |
| 按钮按下 | `transform: scale(0.97)` + 背景变 `-press` | 150ms / standard | 释放回 1，不做回弹 |
| 卡片按下 | `transform: scale(0.98)` | 150ms / standard | 仅海报卡，列表行用背景高亮 |
| Toast 进入 | `translateY(8px→0)` + `opacity(0→1)` | 200ms / decelerate | 退出 150ms / accelerate |
| BottomSheet | `translateY(100%→0)` | 300ms / decelerate | 遮罩 `opacity 0→1` 同 300ms |
| Dialog | `scale(0.96→1)` + `opacity` | 200ms / decelerate | 遮罩独立 200ms |
| 控制条显隐 | `opacity` | 300ms / standard | 不使用位移，避免画面抖动 |
| 页面转场 | `transform: translateY(6px→0)` | 200ms / decelerate | **只做进入、只动 transform**：不使用 opacity（动画被冻结时内容会不可见），也不使用 out-in 双阶段（连续导航会卡住） |
| Tab 切换指示 | `background-color` | 150ms / standard | 不使用滑动指示条（4 个 Tab 无需） |
| 骨架扫光 | `translateX(-100%→100%)` | 1400ms / linear，无限 | 见 §7.3 |
| 进度条填充 | `width` | 无过渡（实时跟随）+ 100ms 平滑 | 拖动时禁用过渡，避免"追赶" |
| 收藏心跳 | `scale(1→1.15→1)` | 150/150ms | 仅成功收藏时一次 |

### 7.3 骨架屏动画

```css
.skeleton {
  background-color: var(--color-bg-skeleton);
  position: relative;
  overflow: hidden;
}
.skeleton::after {
  content: '';
  position: absolute;
  inset: 0;
  transform: translateX(-100%);
  background-image: linear-gradient(90deg,
    rgba(255,255,255,0) 0%,
    var(--color-bg-skeleton-shine) 50%,
    rgba(255,255,255,0) 100%);
  animation: skeleton-shimmer 1400ms var(--ease-standard) infinite;
}
```

必须遵守：
1. 骨架块形状 = 真实内容形状（海报骨架 2:3 + 圆角 12px；标题骨架高 12px ×2 行）。
2. 骨架数量 = 首屏可见数量（不渲染 30 个不可见的骨架）。
3. `prefers-reduced-motion: reduce` 时停止扫光，只保留静态底色。

### 9.2 主题应用规则

1. 主题只改 `data-theme` 属性，**不改结构**；所有组件必须同时支持两套。
2. 播放器区域**不随主题变**：画布恒为 `#000`，控制条文字恒为白色（观影时不打断暗适应）。
3. 海报卡片的海报本身不受主题影响，只改标题与边框色。
4. `theme: 'system'` 时监听 `prefers-color-scheme`，切换生效 ≤ 500ms（AC-88）。
5. 主题切换时禁用 transition 100ms，避免整页"泛白"闪烁（切换完成后恢复）。

**交互态叠色**：组件禁止再硬编码 `rgba(255,255,255,x)`。深色主题靠白色叠加提亮，浅色主题必须换成墨色叠加——白叠白等于不可见（关闭态开关轨道、进度条底槽、抽屉把手、各类按压反馈都会整体消失）。海报角标与播放器区域是例外（§9.2 第 2/3 条），它们恒在深色画布上，继续用白色叠加。
