## 0. 说明

- 覆盖 **18 条路由记录 / 17 个视图组件**（`SourceFormView` 复用 new 与 edit 两条路由）。
- 每页固定小节：**线框 → 信息层级 → 四态 → 关键交互 → 数据与状态来源 → 验收 AC**。
- 线框中的数字表示 4pt 间距 token（4 = `--space-1`，8 = `--space-2`，以此类推），高度为 px。
- 四态 = `loading / empty / error / offline`（技术方案 8.2），`refreshing` 视作 loading 的轻量变体单独说明。
- 所有页面默认深色主题；浅色主题仅替换颜色 token，不改布局。

### 全局页面骨架

```
┌──────────────────────────────────────┐ ← status bar
│            safe-top                  │
├──────────────────────────────────────┤
│ [←44] 标题 24/32            [操作 44]│ 顶栏 52（吸顶，背景 bg-base 90% + blur）
├──────────────────────────────────────┤
│                                      │
│            内容区（滚动）             │ padding-x 16
│                                      │
├──────────────────────────────────────┤
│  首页   媒体库   下载   我的          │ TabBar 56 + safe-bottom（仅 4 个一级页）
└──────────────────────────────────────┘
```

顶栏三态：
1. **一级页**（Home/Library/Downloads/Settings）：左侧 App 名或页名，右侧 1 个操作（搜索/筛选/设置）。
2. **二级页**（Detail/History/Favorites/Sources/Forms/Backup/About/Compliance/Search）：左侧返回，中间标题，右侧 0–1 操作。
3. **沉浸页**（Player）：无顶栏，控制条叠在画面上。

### 1.4 关键交互

| 交互 | 行为 |

| 滚动到底 | 主按钮不做"必须滚到底才可点"的强制（声明完整展示在卡片内） |

### 1.5 数据与状态

`settingsStore.load()` → `settings.complianceAcceptedAt`、`complianceVersion`；成功后 `router.beforeEach` 放行。

**验收**：AC-100、AC-101、AC-102。

### 2.2 信息层级

| 顺序 | 内容 | 理由 |
| --- | --- | --- |
| 1 | 「继续观看」横滑区 | 家庭用户"点开就接着看"是最高频动作（场景 A/B） |
| 2 | 「最近添加」网格 | 发现新内容；来自 `libraryService.listRecent()` |
| 3 | 底部 Tab | 全局导航 |

### 2.3 四态

| 态 | 表现 |
| --- | --- |
| loading | 骨架：继续观看 3 张（132×198）+ 网格 6 张（含 2 行标题骨架）；不做整页 spinner |
| empty | 有源但无内容：「还没有内容」+「去媒体库看看」+ [刷新]；继续观看区整块不渲染（不留空容器，AC-64） |
| error | 顶部错误卡（`min-height: 120px`）：`ERROR_MESSAGES[code]` + [重试]；下方若已有缓存数据仍展示 |
| offline | 顶部 `OfflineBanner`（高 32 + safe-top）+ 展示 IndexedDB 缓存；继续观看为本地数据，正常展示 |
| refreshing | 下拉刷新时顶部出现 32px spinner 区，列表内容不闪烁、不回到骨架 |

### 2.4 关键交互

| 交互 | 行为 |
| --- | --- |
| 点击继续观看卡 | `router.push('/player/' + mediaId + '/' + episodeId)`，起播位置 = `progressOf()` |
| 点击卡片「移除」 | 立即从列表移除（乐观更新）→ `historyStore.remove(id)`；失败回滚 + Toast |
| 点击海报 | `router.push({name:'detail', params:{mediaId}, query:{sourceId}})` |
| 点击搜索图标 | `router.push('/search')` |
| 下拉刷新 | 阈值 64px；触发 `loadFirstPage(true)` + `historyStore.load()` |
| 长按海报 | 底部弹出快捷 Sheet：[收藏/取消收藏]、[下载]、[查看详情] |
| 点击 Tab | `router.push`，重复点击当前 Tab 滚回顶部 |

### 2.5 数据与状态

`historyStore.continueWatching`（≤10 条，5%<p<95%）、`libraryStore.listRecent(20)`、`uiStore.isOffline`、`settingsStore.hideDemoContent`。

**验收**：AC-63、AC-64、AC-95、AC-98、AC-27。

### 3.5 数据与状态

`sourceStore.enabledSources` / `currentSource`、`libraryStore.categories` / `currentCategoryId` / `filters` / `items` / `page` / `hasMore` / `state`；筛选条件会话级保留（路由返回不重置）。

### 4.1 线框

```

│       │ 🔍 搜索片名…      ✕ │       │ SearchBar 40 r-full

│ 🕐 sintel                        ✕   │
├──────────────────────────────────────┤
│ 本地结果                             │ title-3（有远程时显示分组）
│ [海报64×96] 片名                     │ ListRow 88
│             2008·电影 · 本地缓存      │
│ [海报64×96] 片名                     │
│             2021·剧集 · 家里NAS       │ caption 显示来源
├──────────────────────────────────────┤

│ [海报64×96] …                        │
└──────────────────────────────────────┘
```

### 4.2 信息层级

1. 搜索框（自动聚焦，光标就位）
2. 历史（关键词为空时）/ 结果（有关键词时）
3. 结果按「本地 → 远程」顺序分段，**本地结果先出 ≤100ms**（AC-22）

### 4.3 四态

| 态 | 表现 |
| --- | --- |
| loading | 本地瞬时返回；远程在底部显示「正在搜索 N 个源…」+ 16px spinner，不遮挡已有结果 |
| empty（初始） | 显示搜索历史（无历史时显示「试试搜索片名或演员」+ 3 个示例词） |
| empty（无结果） | 「没有找到相关内容」+「换个关键词，或检查源是否启用」；输入框内容保持可编辑（AC-23） |
| error（全部源失败且无本地） | 错误卡 + [重试] |
| error（部分源失败） | 结果正常展示 + 底部黄字「部分源搜索失败（2）」可点开看明细（AC-24） |
| offline | 横幅 + 只搜本地缓存；搜索框下方提示「离线，仅搜索本地缓存」 |

### 4.4 关键交互

| 交互 | 行为 |
| --- | --- |
| 输入 | 防抖 300ms 触发；新输入取消上一次请求（`AbortController`）；本地先出 |
| 确认搜索 | 写入搜索历史（去重、置顶、≤10 条） |
| 点击历史词 | 填入并立即搜索 |
| 单条删除 / 清空 | 滑动或点 ✕ 删除；「清空」需二次确认 |
| 点击结果 | 进入详情（带 sourceId）；并写入历史 |
| 返回 | 若输入框有内容，先清空；再按返回退出页面 |

### 4.5 数据与状态

`libraryStore.search()` → `searchResults` / `searchState` / `searchFailed`；`settingsStore.settings.searchHistory`。

**验收**：AC-22、AC-23、AC-24。

## 18. 跨页公共规则

### 18.1 顶栏行为

| 场景 | 行为 |
| --- | --- |
| 吸顶 | `position: sticky; top: 0`，背景 `bg-base` + 向下 8px 渐变到透明，滚动时持续可见 |
| 标题超长 | 1 行省略，点击标题可滚动到页首 |
| 返回 | 优先 `router.back()`；直接进入（无历史）时按层级回退（详情→首页、二级设置→设置） |
| 右侧操作 | 最多 2 个；超出收入 ⋯ 菜单 |

### 18.2 下拉刷新

| 页 | 支持 |
| --- | --- |
| Home / Library / Downloads / History / Favorites / SourceList | 是 |
| Detail | 否（进入时自动后台刷新，顶部细进度条） |
| Search / Forms / Player | 否 |

下拉阈值 64px，指示器为 24px spinner，松手后最小展示 400ms（避免闪烁）。

### 18.3 Android 返回键优先级

```
1. 有打开 BottomSheet / Dialog  → 关闭
2. 播放器全屏                    → 退出全屏
3. 页面在 tab 根                 → 不退出（或二次确认退出 App）
4. 其它                          → router.back()
```

### 18.4 离线横幅

`OfflineBanner` 固定在顶栏下方（`top: calc(52px + safe-top)`），高 32px，`--color-info-soft` 底，文字「离线模式，展示本地缓存」。网络恢复后 2s 自动消失并 Toast「网络已恢复」。

### 18.5 权限与合规红线（设计侧）

1. 任何页面不得出现内置的第三方片源地址、Logo、或"资源站"入口。
2. 「新增源」「导入订阅」「关于」「合规声明」四处必须有合规说明。
3. 演示内容在所有列表均带「演示」角标（`isDemo`）。
