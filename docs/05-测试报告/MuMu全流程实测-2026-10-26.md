# MuMu 全流程实测报告 — 2026-10-26

> 环境：MuMu 安卓模拟器 12（x86_64），adb `192.168.3.3:5555`，APK 由当前 main（4445420）构建。
> 方法：adb 安装 + WebView DevTools（`scripts/mumu-driver.cjs`，CDP 直连）+ logcat 取证 + 直接调用原生 Spider 插件验证。

## 一、结论（TL;DR）

**「很多都播放不了」的两个真正根因已定位并修复，spider 源从「全军覆没」变为「链路打通」。**

| 链路 | 修复前 | 修复后 |
|---|---|---|
| CMS 直连源（红牛等） | ✅ 正常（库→详情→播放 0:03/8:10） | ✅ 正常 |
| spider-jar 源（潇洒 99 源） | ❌ **100% 调用失败**（NoSuchMethodError） | ✅ **搜索→详情→播放 0:14/46:18** |
| 聚合搜索 | ❌ 只有演示数据 | ✅ **122 部 / 188 条来源** |
| 首页 | ❌ 只有演示内容 | ✅ 真实内容 + 继续观看 |

两个根因都在**原生爬虫运行时**，与网络、源质量、播放器无关：

1. **`com.github.catvod.crawler.Spider` 缺 `safeDns()` 静态方法** → 每次调用抛 `NoSuchMethodError`（119 次实测复现），爬虫加载成功但一调用就失败。表现为「源健康检测通过、点进去空白/失败」。
2. **jar 内 `com.github.catvod.spider.Init` 的 Context 未注入** → `Init.context()` 返回 null，爬虫在 detailContent 里 `context.getPackageName()` 直接 NPE（YunDuo 等实测）。

## 二、修复内容（已改代码，未提交）

### 1. `Spider.safeDns()` — 补 TVBox 基类静态契约

`android/app/src/main/java/com/github/catvod/crawler/Spider.java`

```java
public static Dns safeDns() { return Dns.SYSTEM; }
public static android.app.Activity getActivity() { return null; }
```

### 2. `SpiderApi` 补两个 TVBox 方法

`SpiderApi.java`：`getAddress(boolean)`、`multiReq(JsonArray)`（返回 `"[]"` 走单请求降级）。

### 3. `Init` Context 注入 — 新增 `injectCatvodInit()`

`SpiderPlugin.java`：`DexClassLoader` 创建后，反射给 jar 内 `com.github.catvod.spider.Init` 的 `Application`/`Context` 类型字段填宿主 Application（兼容静态字段与 `Init.get()` 单例字段两种混淆形态）。日志实测 `injected catvod Init context (1 field(s))`。

**验证证据（logcat）**：
- 修复前：`NoSuchMethodError: No static method safeDns()Lokhttp3/Dns;` × 119 次
- 修复后：0 次；`injected catvod Init context` 每 jar 1 次；`sp-16/sp-22` 全链路返回可播放 URL

## 四、需要修改优化的清单

### P0（已完成，真机验证通过）

- [x] **`Spider.safeDns()` 缺失** — 补静态方法（spider 源全军覆没的根因）
- [x] **`Init` Context 未注入** — 反射注入 Application（detailContent NPE 的根因）
- [x] **`SpiderApi.getAddress(boolean)` / `multiReq(JsonArray)` 缺失** — 补齐契约
- [x] **ABI 预检（崩溃修复）** — ftyguard 系 jar 的 native `.so` 在 x86 模拟器上触发
      JNI abort（`SIGABRT` 杀进程，Java catch 无效）。新增 `assertNativeAbiSupported()`：
      加载前扫 jar 内 ELF 头取 ABI，与**设备主架构**（`SUPPORTED_ABIS[0]`）比对，不符即拒。
      注意不能用 `SUPPORTED_ABIS` 全集判断——MuMu 带 ARM 转译层，会列出 `arm64-v8a`
      导致误判放行。同时 `runSpider` 的 `catch (Exception)` 改为 `catch (Throwable)`
      （`UnsatisfiedLinkError` 是 Error 不是 Exception）。

### P1（已全部完成）

1. [x] **`categoryContent` 空 tid 回退**（`SpiderAdapter.ts`）
   UI 选「全部」时 tid 为空串 → 大量爬虫返回空列表（实测枫叶 8 分类全空）。
   现在回退用 `homeContent` 首个分类的 `type_id`，对齐 TVBox 客户端行为。

2. [x] **爬虫异常信息透传**（`SpiderPlugin.describeFailure`）
   反射异常的 `getMessage()` 是 null，之前只显示「爬虫调用失败: null」。
   现在剥离 `InvocationTargetException` 包装，输出「类名: 消息」，并对
   缺方法/缺类/ABI 不符/内存不足给出定论。

3. [x] **健康检测验证可出片**（`SpiderAdapter.probe` 新增 C 段）
   原来只测 `homeContent`，把「jar 能加载但源站已死」判成 ok（修复前 61 个「可用」实际全挂）。
   现在额外拉一次 `categoryContent`，0 条即判 `E_SOURCE_UNAVAILABLE`。

4. [x] **jar 下载重试**（`SpiderPlugin.ensureJarFile`）
   3 次尝试 + 递增退避（800ms/1600ms）；4xx（除 408/429）与 md5 不符不重试。

5. [x] **预热优先当前源 + 并发 2→3**（`sourceStore.warmupSpiderSources`）
   99 个源的订阅里，用户正在看的源最先就绪。

6. [x] **`127.0.0.1:<port>/p/<n>/proxy/<url>` 前缀剥离**（`subscriptionParser.stripLocalProxyPrefix`）
   PG 订阅 5 个 CMS 源因此导入即死；现在解析时还原真实地址（支持 URL 编码内层）。
   非回环 host 保持原样（可能是用户网络里的真实代理）。

7. [x] **批量清理已禁用源**（`SourceListView.purgeDisabled`）
   体检后残留大量已禁用死源（实测 183 条里 105 条），提供一次性删除入口。

### P2（已完成）

8. [x] **`E_NETWORK` 误用修正**（`LiveView.describeSourceError`）
   直播源挂了却提示「网络不可用」。现在用 `navigator.onLine` 区分：确实离线才用网络文案。

9. [x] **首页死源引导换源**（`HomeView.sourceLooksBroken`）
   当前源禁用/健康异常时，空态与错误卡给出「换源」入口而非笼统「还没有内容」。

10. [x] **健康检测当前源优先**（`sourceService.prioritySourceIds`）
    默认源排最前检测，结果每个源完成即写库，列表实时刷新。

11. [x] **ARM-only jar 明确提示**（`describeFailure`）
    ABI 不符时给出「模拟器转译层无法运行该源的原生代码」，不再是笼统「加载失败」。

## 六、复现命令

```bash
# 构建安装
npm run build:only && npx cap sync android && (cd android && ./gradlew assembleDebug)
adb connect 192.168.3.3:5555
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.qoder.cinema/.MainActivity

# DevTools 通道
PID=$(adb shell pidof com.qoder.cinema | tr -d '\r')
adb forward tcp:9333 localabstract:webview_devtools_remote_$PID

# 驱动
node scripts/mumu-driver.cjs text
node scripts/mumu-driver.cjs hash "#/settings/sources"
```
