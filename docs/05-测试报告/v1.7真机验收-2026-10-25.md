## 2. 验收中发现并修复的缺陷（2 个）

1. **[P1] m3u 被误判为多仓索引**：直播 m3u 的频道 URL 行命中 `reposOf` 的「逐行 URL 文本」分支，直播建议永不触发（真机首次复测发现）。修复：`previewFromRaw` 中直播列表判定优先于多仓识别（`detectLiveList` 命中时清空 repos 再产建议）。回归单测 `importService.spec.ts` 4 例。
2. **[P2] 启动自动刷新未接线**：`maybeAutoRefresh` 服务已实现但无调用点。修复：`bootstrap.ts` 新增 `initSubscriptionAutoRefresh()`（在线时 fire-and-forget），`main.ts` 一行接线。

另有构建期修复：`ExoPlayerPlugin.java` 两处 API 误用（`setDefaultRequestProperties` 批量头、`getContext().getResources()`）。

## 3. 已知边界与遗留

- **JS 渲染型短链（Link3.cc 链接树 SPA）**：首屏 HTML 不含配置链接，静态嗅探按设计失败并给出可读文案。动态渲染嗅探需引入无头浏览能力，超出本期范围；真实可用路径是用户从链接树页复制具体接口地址。
- **模拟器原生 HTTP 栈域名屏蔽**：CapacitorHttp 对部分域名（jszyapi.com、teach.link、qist 系、baidu.com）挂起（系统 curl 同域 200）——环境特性非应用缺陷；受影响的真实清单条目改由本地 fixture 等价验证。
- **AC-123 换线换源链**：未做确定性真机触发（需构造特定坏线路+同名同年跨源组合），自动换线复用真机已验证的 `switchLine` 机制、换源复用 `pickPlayCandidates`（单测覆盖）；建议后续用坏线路源做一次人工触发。
- **AC-125 弹幕帧率 / ExoPlayer PoC 转正**：需真实 4K 片源与长时间帧率采样；ExoPlayer 播放路由接线仍是 Spike 下一步（开关与插件已就绪）。
- **dandanplay API**：凭据未申请，弹幕当前实际走聚合备源（无凭据可用）。
