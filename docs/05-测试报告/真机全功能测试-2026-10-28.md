## 问题清单与修改方案

### P0-1 播放解析成功率极低（核心体验问题）

14 源探测仅 **1 例**完整播起。失败模式：

| 源 | 环节 | 错误 |
| --- | --- | --- |
| 80S磁力 | resolve | E_UNSUPPORTED_FORMAT（magnet: 协议） |
| 火锅APP | resolve | E_PARSE 爬虫未返回数据 |
| 次元动漫 | resolve | E_NO_PLAY_URL（源站侧失败） |
| 旺旺影视 | resolve | **30s 后** E_SOURCE_UNAVAILABLE |
| New6V/七味磁力 | resolve | E_NO_PLAY_URL |
| 儿童启蒙 | resolve | lazy 正则失败 `cannot read property '1' of null` |
| 红果短剧(alist) | browse | E_UNKNOWN「操作失败，请重试」 |

**方案**：
1. resolve 失败细分错误码：`源站真死` / `解析超时` / `协议不支持(磁力)` / `规则脚本异常`，UI 按类给「换源」「稍后重试」「外部播放」不同引导，而不是一律「该源暂不可用」。
2. 红果(alist) 的 E_UNKNOWN 需要包一层错误映射，把底层异常翻成可读文案。

### P0-2 ExoPlayerPlugin.progress() 非主线程访问 → FATAL 崩溃

logcat crash buffer 实证两次（10-27 20:08 / 20:11）：
`IllegalStateException: Player is accessed on the wrong thread` at `ExoPlayerPlugin.java:219`（`getCurrentPosition`）。
同文件 `setRate/setVolume/release` 都正确包了 `executeOnMainThread`，唯独 `progress()` 直接在 CapacitorPlugins 线程读 player。

**方案**：`progress()` 全体包 `getBridge().executeOnMainThread()`，在主线程内取值后 `call.resolve(result)`。

### P0-3 健康探测误判：92 个可用源被标 unreachable

- 探活超时 `TIMEOUT_TEST_CONNECTION_MS = 3000`（constants.ts:55），而 ftyguard 类 jar 冷启动（1MB 下载 + dex 加载 + 防护初始化）远超 3s；
- 实证：`飞球体育` health=unreachable，但真实 openSource 90s 窗口内 success（30 条目）；
- 风险链：`sourceStore` 的 autoDisable 会把 unreachable+healthCheckedAt 的源自动禁用 → **92 个好源面临被禁**；
- 搜索不受影响（candidates 不按 health 过滤），但 UI 长期误标。

**方案**：
1. spider 源探活超时分级：jar 冷加载路径放宽到 10~15s（或首检 15s/复检 5s）；
2. 通用兜底：真实 browse/resolve 成功时若当前 health 为 unreachable，回写 ok（使用即校准）；
3. autoDisable 前对 unreachable 源做一次复检，避免一次抖动直接禁源。

### P1-4 磁力源不可播但无引导

80S磁力 resolve 已能识别出 `magnet:` 且通过协议校验（SpiderAdapter.ts:658 放行），但 App 无种子下载/外部播放链路，用户点击必失败。
**方案**：识别 magnet: 后明确报「磁力链接需外部播放器」，提供 intent 跳转（`market://`/第三方播放器）；源卡片/详情页对纯磁力源打「磁力」标，降低预期。

### P1-5 错误文案泄露内部实现

真机日志可见 `cannot read property '1' of null`、`'data' is not defined`、`expecting ';'`、`'rule_fetch_params' is not defined` 等原始 JS 异常直接进 `searchFailed` 明细。
**方案**：drpy/js 规则异常统一映射为「规则脚本异常（源站问题）」，原始信息仅入日志/调试面板。

### P1-6 resolve 首次 30s 长等待

旺旺 resolve 30254ms 才报错（jar 未加载时逐个试镜像候选）。
**方案**：jar 已缓存命中时 playContent 单次超时 10s 直接失败；只有下载/镜像链路才允许 30s。同时首页/详情可预热 jar。

### P1-7 catvod 桩兼容缺方法 → SIGABRT 杀进程

10-27 20:16 实证：加载某 jar 时 `NoSuchMethodError: no static method InitOrigin.setClass` 经 JNI 直接 SIGABRT（DexNative.getLoader → Init.init → SpiderPlugin.loadSpider:591）。
**方案**：补 `InitOrigin.setClass(Class)` 静态桩（以及同族缺失 API），并在 `loadSpider` 外层捕获 Throwable 兜底，防单 jar 拖死整个进程。

### P2-8 drpy 搜索页码 undefined

哔哩直播/我的哔哩搜索请求 `page=undefined` → 源站 502/412。
**方案**：drpy 调 searchContent 时页码缺省补 1。

### P2-9 聚合搜索 30s 收敛偏慢、21 源失败无汇总

失败源已计入 backoff；建议 UI 加「N 个源失败」折叠条 + 一键重试。

### P2-10 WebView renderer 偶发断连

爱看探测后 CDP 断连但进程存活（非崩溃），一次/两天，观察即可。
