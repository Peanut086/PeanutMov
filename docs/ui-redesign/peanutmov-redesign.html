核心浏览

Browse

首页改为「继续观看大卡 + 横滑流」，信息密度更高且一屏可见三类内容；媒体库用 2 列海报墙承载筛选； 详情页改为沉浸式海报背景 + 内容上浮卡片；搜索把历史与结果压进同一滚动区，减少页面跳转。

播放与直播

Playback

播放器控制条改为「无边框 + 玻璃质感」，进度条带拖动时间气泡（上一轮已实现）；手势 HUD 用圆形进度环替代纯文字百分比； 横屏全屏把倍速/清晰度/字幕收进右侧竖排，避免底部两行按钮遮挡画面。

内容管理

Manage

下载/历史/收藏统一为「顶部汇总 + 状态分段 + 内容列表」同一骨架，减少认知切换； 片源管理把 4 个平铺按钮改成 2×2 操作卡，线路质量用分档条形图一次看全。

系统页

System

「我的」把数据概览做成品牌色渐变卡，分组内行高统一 52px、值靠右对齐；引导页把合规要点拆成带序号的条目， 主按钮固定在底部安全区上方；备份页把「导出/导入」拆成两张明确动作卡。
