## 1. 统计口径

- **通过**：按 AC 步骤可复现，且有自动化证据或可核代码/截图证据。
- **不通过**：实测与 AC 预期不符，或 AC 要求的能力完全缺失。
- **未验证**：环境不具备（真机 Android / 真实 AList/WebDAV/Jellyfin 服务器 / 200 张海报大源 / DASH-DRM 流 / 大文件），**非"推定通过"**。
- **部分通过**（归入"不通过"并注明）：AC 中多项预期只有部分满足。
