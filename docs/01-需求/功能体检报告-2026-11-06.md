### 3.1 P0 复现路径（FIX-03）

1. 准备一段 media playlist：`#EXTM3U` + `#EXT-X-KEY:METHOD=SAMPLE-AES,URI="key.bin"` + 若干 `#EXTINF` 分片。
2. 在 App 内对该 m3u8 发起下载；`HlsDownloader` 会成功拉取密钥、逐片下载，但跳过解密。
3. 任务状态变为 `completed`，文件大小正常；本地播放时解码失败/黑屏。
4. 期望：下载开始前或解析清单后直接失败并提示“不支持受保护内容（DRM）”，不得产出完成态文件。

### 3.2 FIX-01 复现路径

1. 设置 → 片源管理 → 新增源：类型只有 AList/WebDAV/Jellyfin/站点，无“采集接口”入口；AC-115 的专用入口不可达。
2. 在内置演示源被禁用/数据被清理后，内联区“内置”开关禁用且无“恢复演示源”，AC-97 无法执行。
3. 连续 3 次体检 bad 的源被自动禁用后，源列表无“已自动禁用”角标；`restoreAutoDisabled` 只在未注册的 `SubscriptionListView` 中调用，用户只能手动打开开关（标记不清除、无摘要）。
4. 源数 183 条时，设置页只见“检查中…”，无 `检测中 n/total`、无取消、无按质量排序。

### 3.3 FIX-04 触发条件

- 用本地 HTTP 服务让 `GET /master.m3u8` 返回 `302 Location: /real.m3u8`，在 Android 真机（CapacitorHttp 生效）发起 HLS 下载。
- 预期：清单也被 `LocalProxy` 转发并跟随 302；现状：第 1 步直连，CapacitorHttp 报 3xx 错误。
