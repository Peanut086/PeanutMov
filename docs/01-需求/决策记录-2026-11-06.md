## 2. 逐条留痕

### Q-01 推荐订阅敏感词口径

- **决策内容**：采用选项 A。`vip` 等敏感词只匹配 `name` 与 `note`；`url` 不参与敏感词匹配，只做域名白名单与 `http(s)://` 合法性校验。保留 `9280.kstore.vip`、`9763.kstore.vip`、`6800.kstore.vip` 三条推荐，内置清单恢复到 10 条。
- **实施口径**：AC-130 的“敏感词表零命中”按新口径解释；新增自动化用例断言过滤后条数落在 8~12、敏感词仅检查 `name/note`、URL 域名白名单生效。
- **影响需求**：FR-56、AC-129、AC-130。
- **影响项**：FIX-02（修复）、REF-03（交叉核对关闭）。
- **需同步文档**：本报告 FIX-02 行与 Q 表；SRS FR-56 增加口径注；测试用例文档补充 AC-130 用例。
- **确认**：2026-11-06，JavaScript大王。

### Q-02 SAMPLE-AES / DRM 处理策略

- **决策内容**：采用选项 A。播放与下载均在清单解析阶段直接拒绝 `METHOD=SAMPLE-AES`（以及 DASH/DRM），提示“不支持受保护内容”，不创建 HLS 实例、不产出“完成态”文件。
- **实施口径**：拒绝发生在下载任何分片之前；错误码沿用 `E_DRM_PROTECTED` / `E_FORMAT_UNSUPPORTED` 既有口径；不投入 DRM 绕过或解密能力。原生 ExoPlayer 的 DRM 实验分支与 AC-40 的边界在实现评审中确认，不得静默放开受保护内容。
- **影响需求**：FR-17、AC-40。
- **影响项**：FIX-03（修复）；EXT-04（下载前可用性预检）；EXT-07（原生 DRM 能力边界）。
- **需同步文档**：本报告 FIX-03 行与 Q 表；技术方案播放/下载边界说明；测试用例新增 SAMPLE-AES 下载拒绝；契约变更 v1.8 的真机验收项。
- **确认**：2026-11-06，JavaScript大王。

### Q-03 网盘平台能力范围

- **决策内容**：采用选项 A。仅保留夸克的账号/会员 API 能力；UC、123、天翼、阿里保留通用 Cookie 直填登录，但 UI 与文案统一标注“**Cookie 直填、账号能力未验证**”，不展示会员/容量/转存等未实现能力。
- **实施口径**：本轮不逆向第三方 API；EXT-02 只做声明收敛与只读信息展示，任何 API 补齐必须另立需求并完成第三方授权与合规评估。
- **影响需求**：无独立 FR/AC；关联 SRS §1“网盘接入”目标与 FR-02 源接入字段。
- **影响项**：OPT-05（能力披露收敛）、EXT-02（范围收敛）。
- **需同步文档**：本报告 OPT-05/EXT-02 行与 Q 表；设置页“网盘账号”行与 `NetdiskSettingsView` 平台文案；用户手册网盘章节；技术方案网盘能力说明。
- **确认**：2026-11-06，JavaScript大王。
