## 5. 缺陷与修正记录

### D-01（已修复｜严重）路由过渡在连续导航时卡死并导致内容不可读

| 项 | 内容 |
| --- | --- |
| 现象 | `<Transition name="fade" mode="out-in">` 在 leave 阶段再次导航时，`fade-leave-active` 不卸载、`transitionend` 不触发，新页面停在 `opacity≈0.35`；实测后续导航也不再生效 |
| 根因 | `mode="out-in"` 依赖 leave 动画结束才插入新节点；60ms 内连续导航会把中间态固化 |
| 影响 | 首页 ↔ 媒体库快速切换（真实用户常见操作）后页面变暗、路由无响应 |
| 修正 | 移除 `<Transition>`，改为 `.route-view` 上的**纯进入动画**；并把动画属性从 `opacity` 改为 `transform: translateY(6px→0)` |
| 二次修正原因 | 只改 keyframes 仍用 `opacity` 时，在被冻结的动画环境中会停在 `opacity:0`（实测 `getComputedStyle` 为 `0`），内容完全不可见。改为位移动画后，最坏情况只是偏移 6px，内容始终可读 |
| 验证 | §4.4 回归通过；`typecheck` / `build` / 6 项自检全部通过 |
| 文档同步 | `设计规范.md` §7.2「页面转场」已改为 transform-only 并写明原因 |

### D-02（已修复｜中）底部 TabBar 遮挡页面内容

| 项 | 内容 |
| --- | --- |
| 现象 | `/library` 截图显示占位卡片被 TabBar 遮住底部；TabBar 为 `position: fixed`，页面自身没有为它留白 |
| 根因 | 留白责任不清：原先约定由各页面自己加 `padding-bottom`，占位页未加 |
| 影响 | 若保持原方案，17 个页面需各自重复实现，必然出现遗漏 |
| 修正 | 在 `App.vue` 外壳统一预留：`.app-content--tabbar { padding-bottom: calc(56px + safe-bottom) }`，由 `meta.requiresLayout` 自动开关 |
| 验证 | 截图复核内容与 TabBar 不再重叠；自检用例分别断言"一级页有留白 / 二级页无留白" |

### D-03（已修复｜中）依赖 `@capacitor/keep-awake` 不存在

| 项 | 内容 |
| --- | --- |
| 现象 | `npm install` 失败：`404 Not Found - GET https://registry.npmjs.org/@capacitor%2fkeep-awake` |
| 根因 | 技术方案 2.1 写的是 `@capacitor/keep-awake ^7.0.0`，但该包在 npm 官方源与淘宝镜像**均不存在**（官方插件已迁至 community） |
| 修正 | 替换为 `@capacitor-community/keep-awake ^7.1.0`（对应 Capacitor 7，7.x 最新为 7.1.0） |
| 影响面 | 仅 `package.json` 依赖名；`DeviceService.keepAwake()` 的调用方（PKG-B `deviceService.ts`）import 路径随之改为 `@capacitor-community/keep-awake`，**契约签名不变**，不影响 API-12 |
| 备注 | 需回写技术方案 2.1（本轮未改文档，交由 PM/方案方登记为 v1.1 变更） |

### D-04（已修复｜低）vitest 与 vite 版本双实例导致类型冲突

| 项 | 内容 |
| --- | --- |
| 现象 | `typecheck` 失败：`vitest.config.ts` 中 `defineConfig` 的 `plugins` 类型不可赋值，报错链长达数十行 |
| 根因 | `vitest@2.1.9` 依赖 `vite@5`，项目用 `vite@6`，出现两套 `Plugin` 类型 |
| 修正 | 升级 `vitest` / `@vitest/coverage-v8` 至 `^3.2.7`（peer 支持 `vite ^5 \|\| ^6 \|\| ^7`），`npm ls vite` 确认全部 dedupe 到 `6.4.4` |
| 影响面 | 仅 devDependencies；测试 API（`describe/it/expect`）用法不变 |

### D-05（已修复｜低）占位页 `display:grid` 导致正文按 `max-content` 撑宽

| 项 | 内容 |
| --- | --- |
| 现象 | 首版占位页 `.placeholder-body` 用 `display:grid; place-items:center`，长中文句子不换行、撑出容器 |
| 修正 | 改为 flex + `min-width: 0` + 正文 `max-width: 32ch` + `overflow-wrap: anywhere` |
