## 5. 复测方式

采集站稳定性差，导入前建议重跑：

```bash
node scripts/cms-probe.cjs scripts/fixtures/zhihu-tvbox-urls.txt --report
```

工具会重新解析全部订阅、逐个实测 CMS 站点，覆盖写入 `scripts/fixtures/cms-alive.json`。
常用选项：`--name <订阅名>`、`--out <目录>`、`--concurrency N`、`--timeout <ms>`、`--json`。

判定"可用"的标准：HTTP 200 + TVBox JSON + 列表非空 + 详情可取到直连播放地址
（非 `?url=` 解析包装）。
