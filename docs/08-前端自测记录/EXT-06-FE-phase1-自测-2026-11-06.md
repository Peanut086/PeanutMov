## 2. 关键实现决策（与方案一致，记录供验收核对）

1. **四级匹配「命中即停 + 整源采纳」**：`matchXmltvChannel` 依 L1 `tvg-id` → L2 `tvg-name`(display-name) → L3 归一化名称 → miss；任一源命中即返回，**不做节目级拼接**（AC-157/158）。
2. **`matchMode` 门槛**：`xmltv-id` 关闭 L2/L3；`channel-name` 关闭 L1；`auto` 全开。
3. **缓存键**：`epgv2:{sourceId}:{channelKey}:{yyyy-MM-dd}`；`programmes()` 兼容键 `epgv2:builtin:...`，`clearSourceCache('epg-builtin')` 一并清理；迁移时旧键空间整体 `clear()`（纯缓存，可重建）。
4. **失败语义**：单源失败记入 `result.errors[]` 并继续下一源；全部失败返回空数组不抛穿（EPG 缺失不影响播放）；失败不写缓存；有过期缓存则返回并置 `stale=true`。
5. **上限与探测顺序**：`add()` 先做名称/地址/重复地址/用户源上限/**启用上限**校验，全部通过后才发探测请求（避免无谓网络）；启用上限不再"静默降为停用"，直接 `E_INVALID_STATE`（AC-155「第 6 个启用源被拒绝」）。
6. **`limits()` 防御**：`AppSettings.epg` 被写成 `0`/`NaN` 时回落常量，避免把功能锁死。
7. **回看能力探测**：HEAD（`throwOnHttpError:false`）→ 2xx/3xx 直接判可用；HEAD 失败再 GET + `Range: bytes=0-1023`；结果进 kv `live-catchup-probes`，6h TTL，写入时顺手清理过期项；同 key 并发共享 Promise；并发闸门 ≤2；原生环境优先 LocalProxy、失败回退直连。
8. **提醒**：`id = r_${fnv1a(channelKey:startAt).toString(16)}`（确定性 → 重复设置落到同一条、`nativeId` 不变）；状态机 `scheduled→firing→fired`、`scheduled/firing→missed`（`startAt + 10min` 宽限）；上限只统计**非终态** 50 条；通知权限 `denied`/`unsupported` 时 `lastError='仅 App 内提醒'` 并保留页内提示，不静默失败；无常驻定时器（启动 + 回前台 `reconcile`），`startAutoReconcile` 返回取消函数避免监听泄漏。
9. **分组/排序作用域隔离**：一条 `channelPrefs` 记录对应一个 `liveSourceId`，不同直播源互不影响（Q-19/Q-22）；失效项（频道被删）沉底不渲染，`countOrphans`/`prune` 提供「清理失效排序项（n）」。
